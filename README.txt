УБАИТ · Story Map — полный пакет сайта для GitHub / Amvera
Сборка: 2026.10.29-v2.1

ЧТО ЗАГРУЗИТЬ
Распакуйте ZIP. Загрузите СОДЕРЖИМОЕ в корень репозитория GitHub
с заменой одноимённых файлов. Не сам ZIP и не дополнительную папку.
Dockerfile, amvera.yml, index.html и server.mjs должны лежать рядом.
check-build.mjs тоже обязателен: он проверяется при сборке Docker.
Не оставляйте рядом второй, старый amvera.yaml: конфигурация в этом пакете
называется amvera.yml. Если старый файл есть, сохраните копию и удалите
именно старый amvera.yaml из репозитория этого сайта.

ЧТО ОСТАВИТЬ В AMVERA
Существующую переменную STORY_MAP_WEBHOOK_URL с рабочим адресом вебхука.
Адрес и секреты в GitHub добавлять не нужно. Флоу n8n и БД не меняются.
Пакет рассчитан на ранее обновлённый API Story Map: schema_version=1,
api_revision=2. Если API старый, интерфейс покажет явное сообщение.

ПОСЛЕ ЗАГРУЗКИ
Amvera должна собрать и развернуть новый коммит из подключённой ветки.
Простого перезапуска старого контейнера недостаточно.
Если GitHub ещё не подключён к Amvera, загрузка в GitHub сама по себе
не обновит сайт: потребуется подключение репозитория.

КАК УЗНАТЬ НОВУЮ ВЕРСИЮ
Рядом с Story map в шапке: v2.1 · 29.10.
В логах запуска: Story Map 2026.10.29-v2.1 listening ...
По адресу сайта /healthz: {"ok":true,"version":"2026.10.29-v2.1"}.
Если там другая версия, сервер обслуживает другую сборку. Это не повод
ещё раз менять флоу или SQL.

В ЭТОЙ ВЕРСИИ
- Раздельные фильтры: год проектов и месяц/квартал историй.
- Стрим = service; направление = value_stream; отдел = branch.
- Done свёрнут; проекты с 100% готовностью скрыты по умолчанию.
- Фильтры готовности проектов/эпиков, кнопка сброса, компактная шапка.
- Собственное окно фильтров, постоянная горизонтальная прокрутка.
- Настоящие названия эпиков; SP, аналитик и готовность на карточках.
- В карточках WIP дополнительно виден конкретный статус.

СОСТАВ
index.html       — весь интерфейс, без отдельных CSS/JS-файлов.
server.mjs       — сервер и запрос к существующему вебхуку n8n.
Dockerfile       — сборка и запуск Node.js без npm-зависимостей.
amvera.yml       — конфигурация Amvera, порт 8080.
check-build.mjs  — проверка версии и синтаксиса при сборке.
.dockerignore   — в контейнер попадают только файлы приложения.
.gitignore      — исключения для локальных секретов и временных файлов.
README.txt      — эта инструкция.

Реальные данные, пароли, токены и выгрузки n8n в пакет не включены.
Авторизации пока нет, как было согласовано: посетитель с адресом сайта
может читать данные. Ограничение доступа отдельно ещё не настроено.
